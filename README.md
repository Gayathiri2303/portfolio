# Gayathiri R — Portfolio

Professional dark-themed portfolio for **Data Science & AI/ML Engineer**.

## Features

- Modern dark theme with cyan accent
- Particle background with mouse interaction
- GSAP scroll animations & page-load sequence
- Fully responsive (mobile → desktop)
- Smooth scroll navigation
- Loading screen
- Hover micro-interactions on cards

## Structure

```
gayathiri-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## How to Run

Just open `index.html` in any modern browser.  
No build step required. Works offline after first load (CDN assets).

## Deploy

Upload the entire folder to any static host:
- GitHub Pages
- Netlify
- Vercel
- cPanel / VPS
